# დემენცია ოჯახში — პრაქტიკული ცნობარი

საინფორმაციო და პრაქტიკული პორტალი დემენციის, ალცჰეიმერისა და მონათესავე მდგომარეობების მქონე პირთა ოჯახის წევრებისა და მომვლელებისთვის.

პლატფორმა ეფუძნება საერთაშორისო კლინიკურ გაიდლაინებს:
- **Teepa Snow (PAC — Positive Approach to Care)**: მხედველობის ველის ადაპტაცია, მიახლოების წესები, „Hand-under-Hand“ ტექნიკა.
- **Naomi Feil (Validation Therapy)**: ემოციის ვალიდაცია და რეალობის ძალდატანებითი შესწორების თავიდან არიდება.
- **Alzheimer's Association & NICE Guidelines**: 4 ძირითადი დემენციის ფორმის დიფერენციაცია, PAINAD ტკივილის შეფასება, Sundowning-ის მართვა.

## ძირითადი მოდულები
1. **კოგნიტური საფუძვლები**: ნეიროფსიქოლოგიური მექანიზმები და 4 ძირითადი სინდრომი.
2. **მხედველობის ველი და მიახლოება**: გვირაბისებრი ხედვის ინტერაქციული სიმულატორი.
3. **ქცევითი სცენარები და ალგორითმები**: 8 ტიპური კრიზისული სიტუაცია, დეესკალაცია და რეკომენდებული ფრაზები.
4. **ტკივილისა და ინფექციის დეკოდირება**: PAINAD გაიდლაინი, UTI, ყაბზობა, სენსორული დისკომფორტი.
5. **სიტყვების ხიდი & Hand-under-Hand**: არასწორი vs სამკურნალო კომუნიკაცია.
6. **უსაფრთხო სახლი**: 4 კრიტიკული ზონის ადაპტაცია (მუქი ხალიჩები, სარკეები, კონტრასტები).
7. **Sundowning**: საღამოს აჟიტაციის სინდრომის მართვა.
8. **4-7-8 სუნთქვის ტექნიკა**: მომვლელის თვითრეგულაცია და ბრაუზერში Web Audio სინთეზირებული წვიმის ხმები.
9. **გადაუდებელი წითელი ალმები**: დელირიუმი, FAST ინსულტის პროტოკოლი, დეჰიდრატაცია (დისფაგიის სიფრთხილე).
10. **ვიზიტორთა მემორანდუმი & დღის რუტინა**: ცირკადული ბალანსი და ვიზიტორთა ქცევის 5 ოქროს წესი.

## ტექნოლოგიური სტეკი
- სუფთა HTML5, CSS3 (Nordic Clinical Modern დიზაინი) და Vanilla JavaScript.
- Web Audio API ბრაუზერში დამამშვიდებელი ბგერების (White/Pink Noise & Chimes) სინთეზისთვის.
- ადაპტური დიზაინი (Desktop, Tablet, Mobile) და ღამის/დღის რეჟიმის მხარდაჭერა.
